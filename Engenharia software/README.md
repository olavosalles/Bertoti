Atividade 1: Achei interessante a comparação entre engenharia de software e programação. O texto mostra que do mesmo jeito que engenheiros mecânicos, civis, aeronáuticos e de outras disciplinas de engenharia trabalham no mundo real para criar algo concreto, os engenheiros de software também trabalham para construir algo que funcione no mundo real, porem, as vezes com práticas menos rigorosas.

Atividade 2: Achei interessante a ideia de considerar a engenharia de software como uma "programação ao longo do tempo". Isso mostra que não basta criar um código que funcione, é preciso pensar em como ele vai ser mantido e adaptado conforme o projeto e a organização crescem
